# ⚓｜𝐍𝐞𝐨𝐌𝐨𝐝𝐬
説明：Minecraftで理想の世界を創造するためのモッドパック。新たな世界の法則を記述し、君を縛る常識から容易に解放する。ようこそ新世界へ！

## ❱ 概要【Prologue】
艦長のお気に入りの機能と製作用の便利機能をまとめた自作MOD。自分用に欲しい機能をすべて詰め込んだ原液で地図機能やフリールック機能、3Dスキン表現やズーム機能、インベントリを開いても止まらない！インベントリから進捗を直接開けるなどなど。ちなみに**Fabric API不要・通信なし**のこだわり設計。必要なのは Fabric Loader だけ。無駄に丁寧な配慮で、気に入らない機能は外せるオプション付き！

<details>
<summary>～ワールドマップ～</summary>

**Mキー**で、バニラの地図を両手で持った見た目の大きな地図が開きます。歩いた場所は自動で蓄積されます。
- Googleマップ風の操作（ドラッグ・ホイール・ダブルクリックでズーム、現在地へ戻るボタン）
- 森の洋館・海底神殿・村・古代都市などの**構造物**と、見つけた**旗**を自動で記録（近づくまで出ないのでネタバレなし）
- 右クリックで**ピン**を立てられ、アイコンはバニラの地図のものから選択
- **Ctrl+左クリック**でその地点へテレポート（OP／チート有効のみ）

※構造物の自動表示はシングルプレイのみ。ピンは遊んでいる間だけ記憶されます。
</details>

<details>
<summary>～ズーム・自由視点～</summary>

- **ズーム**：素手で右クリックを長押し。既定3倍、ホイールで1〜50倍。なめらかに寄って戻り、感度も自動で下がります。
- **自由視点**：F5を長押しすると、自分の向きはそのままに、カメラだけ360度回せます。離すと元の視点へ。単押しはこれまでどおりの視点切り替えです。
</details>

<details>
<summary>～移動・画面切り替え～</summary>

- **インベントリを開いても移動**：チェストや作業台を開いたまま、歩く・ジャンプ・ダッシュができます。
- **画面の直接切り替え**：進捗画面で **E** → インベントリ、インベントリ・チェスト・本・マップなどで **L** → 進捗画面。
- **進捗画面の拡大**：画面の約85%まで広がって見やすくなります。
</details>

<details>
<summary>～見た目と便利さ～</summary>

- **3Dスキンレイヤー**：帽子・上着・袖・ズボンが立体に。頭ブロックや頭アイテムにも対応。遠くは自動で軽い表示に戻ります。
- **クリックコマンドの確認を省略**：本やチャットのコマンドを即実行（署名が必要なコマンドの確認は残ります）。
- **エンチャント効果のツールチップ**（既定OFF）：エンチャントの具体的な効果を表示。
- **スポナー情報**（既定OFF・クリエイティブ専用）：スポナーの発光・範囲球・文字表示。
</details>

## ❱ 導入【Introduction】
1 配布サイトから「NeoMods.jar」をダウンロード！  
2 下記のPATHの `mods` フォルダに配置。  
3 Fabric のプロファイルで Minecraft 26.3 を起動して冒険開始！  
```Path
%userprofile%\AppData\Roaming\.minecraft\mods
```
（以下任意）  
4 気になる機能は、設定画面からOFFにするとバニラと同じ動作に戻ります。

## ❱ 設定【Settings】
NeoModsの設定画面は、次のどれからでも開けます。
- タイトル画面の下段にある Mods アイコン
- ゲームメニュー（ポーズ画面）のアイコン
- **@キー**（日本語配列。英語配列では `[` の位置）

機能ごとにON/OFFでき、**「既定に戻す」**で初期状態に戻せます。キー割り当ては操作設定の「NeoMod」カテゴリで変更できます。
導入しているModの一覧は、タイトル画面の「Mods」ボタンから確認できます。

## ❱ 機構【NeoMods】
Fabric API を使わず、Fabric Loader 同梱の Mixin だけで動く、独立した構成です。
```
実行時の依存: fabricloader と minecraft のみ
外部通信・テレメトリ・自動更新: なし
設定の保存先: options.txt の neo_ 行（既定値から変えた項目だけ）
OFFの機能の負荷: 入口で打ち切り（バニラと同じ動作）
Mixin: 38個
```
