## ❱ 導入【Introduction】

1. **ダウンロード：** [Project-NEXUS.zip](https://drive.google.com/uc?id=1_fTZHy7KvKvKPt16z1krUL47wZPkO43T) をダウンロード
2. **展開：** すべて展開（解凍）。パスワードは ||neo（ローマ字小文字３文字）||
3. **起動：** `AnchorDrive.exe`（もしくは自分の OS に合った実行ファイル）をダブルクリック
   > 起動をブロックされたら「詳細情報」→「実行」。ウイルス対策ソフトに誤検知された時は、付属の手動起動スクリプトで起動してね。
4. **探索：** 起動できたら、まずは色々あそんでみてね。操作は基本マイクラと同じです。

## ❱ 各種ワールドの遊び方【Howto】

<div align="center">

![THE WORLD OF WONDERS](https://raw.githubusercontent.com/nemonowa/nemonowa.github.io/refs/heads/main/source/asset/map.png)

</div>

1. タイトル画面で「**+Add World**」を選び、「𝐓𝐇𝐄 𝐖𝐎𝐑𝐋𝐃 𝐎𝐅 𝐖𝐎𝐍𝐃𝐄𝐑𝐒」に変更！
2. インストールが完了したら「**DIVE**」開始！
3. サーバーが解放されたら、Minecraft 1.20.4 のマルチプレイで `localhost` と入力
   > 内部サーバーであり、インターネットには公開されていません。
4. ゲーム開始！ 常に最新のワールドに更新されてるよ！ ようこそ新世界へ！
